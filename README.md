# TAC Interview Agent

Windows / macOS 面试辅助应用原型，界面参考 TAC Marketing 素材。当前主线是置顶悬浮窗、系统音频转写、简历上下文和流式回答；此前的整屏共享防采集及原生按键监听作为可选方案保留，不属于当前主线，也不是运行前置条件。

仓库中的 [PROMPT.md](PROMPT.md) 和 [SPEC.md](SPEC.md) 是 2026-11-13 提供的需求文档快照；其中的技术假设不等于实现或验收结果，版本差异及当前限制见 [TECHNICAL-NOTES.md](TECHNICAL-NOTES.md)。

## 本地启动

安装 Node.js 和 npm，在项目目录运行（已使用 Node.js 24 验证；测试需要支持直接加载 TypeScript 的 Node.js 版本）：

```bash
npm install
npm run dev
```

悬浮窗顶部可拖动，默认使用 `Alt/Option+Shift+H` 隐藏或恢复；快捷键可在设置中修改，托盘菜单也提供显示、隐藏和退出。修改主进程代码后需要退出并重新启动应用。

## 使用与数据

- 在设置中填写腾讯云语音识别和所选模型服务的配置。凭证使用系统加密存储；本机不可用时应用会提示。
- 音频检测只在本机进行。明确启动云端转写后，系统音频才会发送到腾讯云；音频缓存在内存中，不写入音频文件。测试时请播放声音并观察电平：音轨存在或产生静音帧不代表已捕获可听声音。
- 简历内容保存在本机应用数据目录；使用云端模型回答时，问题及相关简历片段会发送给所配置的服务商，使用前须在设置页确认。
- 不共享屏幕时悬浮窗正常显示。共享窗口或标签页时仍应以会议软件的实际共享范围为准；共享整个屏幕时悬浮窗可能被看到。应用尝试启用系统采集保护，但不保证对所有会议软件有效。
- 附录 A 的原生监听源码和测试仍在仓库中，但当前应用没有接入监听进程或按住展开功能；编译 helper 或通过其测试不表示该功能可用。

## 检查及当前限制

```bash
npm run typecheck
npm run build
npm test
```

本项目仍是开发原型：自动化测试不能代替真实音频设备、腾讯云、模型服务及会议软件的端到端验收。**macOS 系统音频、权限、签名及打包尚未实机验证**；应用的 Electron 33 与新版 Electron 的音频路径和权限要求不同，增加 Info.plist 字段本身不能证明能够采到声音。开发期运行与签名包的权限归属也需分别验证。

可选原生监听测试仅在对应 Windows helper 已构建时运行；新检出缺少该二进制或在其他系统运行时会显示跳过。主线开发和测试无需构建原生监听器。
